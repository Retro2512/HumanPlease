# Bundled fonts

The WOFF2 files are the Archivo and Martian Mono variable-font subsets served by Google Fonts on
2026-09-03. They are hosted here so page loads do not contact a third-party font service.

- Archivo: SIL Open Font License 1.1; see `Archivo-OFL.txt`.
- Martian Mono: SIL Open Font License 1.1; see `MartianMono-OFL.txt`.
